# 03 — 用例 3：RM AI 副驾（融资 / 税务 / 法律 / 服务邀请）

> **一句话**：RM 不可能同时是融资顾问、税务师、律师和生活管家；但他可以在**一次客户对话**里，判断"这事该找谁、大概怎么做、边界在哪、多久能安排"，并且**不越牌照、不泄数据、不说错话**。
>
> **范围**：香港 + 新加坡；内地不作为销售/招揽市场。

---

## 1. 四个驾驶舱 + 一个服务邀请平台

```
                    ┌─────────────────────────────┐
                    │ PB-300 RM Home / NBA        │
                    │ 今天最值得打的一个电话       │
                    └───────┬─────────────────────┘
        ┌───────────────┬───┴───────────┬──────────────────┐
        ▼               ▼               ▼                  ▼
 PB-310/320        PB-330           PB-340            PB-350/360
 融资驾驶舱         税务驾驶舱        法律驾驶舱         服务 / 邀请
 (SLB/贷款/现金流)  (义务/情景/转介)  (事项/文件/转介)   (RFP/vendor/邀请)
        └───────────────┴───────┬───────┴──────────────────┘
                                ▼
                        PB-370 专家连接 / 案件工作台
```

**设计原则**
1. **RM 是编排者，不是专家**：系统给"判断 + 话术 + 转介"，不给"结论"。
2. **每个建议都带边界**：能做什么、不能做什么、依据哪条规则。
3. **专家是持牌第三方**：银行只做场景识别、转介、资金承接；服务邀请由 HSBC 提供/协调，后台采购由 HSBC 做甲方，vendor 做乙方。
4. **客户数据不随转介流失**：只传"有位客户、需求类别"，不传持仓/账户/交易明细，除非客户单独授权。
5. **SLA 可追**：转介/投标/交付，谁接、多久接、进展如何，全部可见。

## 2. 融资驾驶舱（Financing）

### 2.1 产品矩阵

| 产品 | 抵押/依据 | 典型 LTV / 折扣 | 期限 | 定价 | 适用场景 | 主要风险 |
|---|---|---|---|---|---|---|
| **Lombard / SLB** 证券质押融资 | 上市股票、债券、基金 | UST 85–95%；IG 债 70–85%；蓝筹股 50–70%；高波动股 30–50%；基金 50–70% | 开放/1–3 年 | 基准 + 50–250bp | 不卖股拿流动性、桥接、税务支付 | 追保、流动性、集中度 |
| **Pre-IPO 股权质押** | 非上市股权 | 保守估值 × 20–40% | 1–3 年 | 基准 + 250–450bp | 上市前流动性 | 估值不透明、变现难、契约严格 |
| **住宅/商业按揭** | 房产 | 50–70% | 5–30 年 | 属地按揭利率 | 购房、再融资 | 利率、估值、属地限制 |
| **现金流 / Capital Call 融资** | 应收、基金承诺 | 承诺额 50–80% | 6–24 个月 | 基准 + 150–350bp | 基金出资、企业周转 | 通知期、资金链 |
| **保险保费融资** | 保单现金价值 | 70–95% | 保单期 | 保单贷款利率 | 大额保单 | 保单失效、利率 |
| **艺术/不动产/其他** | 收藏、物业 | 30–50% | 1–5 年 | 个案 | 多元化 | 估值、流动性 |
| **保证金 / 衍生品融资** | 现金/证券 | 按产品 | 滚动 | 内部资金成本 + | 对冲、结构化 | 追保、错向 |

> 利率与 LTV 为行业区间示意，非任何机构报价；实际以授信政策、抵押品、客户关系与法域为准。
>
> **术语提示**：本方案中的 "SLB" 按 **securities-backed lending（证券质押融资）** 理解；若机构口径中的 SLB 指 **securities lending & borrowing（证券借贷）**，属另一条产品线，需单独建模（借券费、担保品、召回风险）。

**LTV 与追保算例（演示）**
- 抵押：1,000 万股 Pre-IPO，保守估值 5 亿美元，折扣 60% → 可贷价值 2 亿美元；LTV 35% → 额度 7,000 万美元。
- 预警线：覆盖率 180%（贷款/可贷值 = 55%）；追保线 160%（62.5%）；平仓线 140%（71%）。
- 若估值下调 30% → 可贷价值 1.4 亿，覆盖率 200% → 安全；下调 50% → 1 亿，覆盖率 143% → 接近平仓，需补股或还钱。
- **结论**：Pre-IPO 质押的折扣必须能承受"估值腰斩 + 上市延迟"双冲击。

**校验**：`ltv > policy_max` → 阻断；`stress_results` 未做 → 不得提交审批。
**异常**：抵押品停牌/估值缺失 → 冻结额度新增，只允许还款。

## 5. 服务与邀请（后台采购）

> **模式纠正**：这不是"第三方入驻、上架、打广告"的市场，而是 **HSBC 作为甲方（principal）的服务与邀请平台**；采购/RFP 是后台流程，不在客户邀请页面展示。：HSBC 定义需求、发布 RFP、审核 vendor、评标、定标、签约；vendor 是乙方，按 HSBC 的规格报价和交付；客户收到的是 **HSBC 的邀请 + 项目 + 交付方**，不需要看到价格、评分、招标、比价与采购过程。

### 5.1 角色与合同结构

> **统一模式**：**所有品类都是 HSBC 采购后免费提供给客户**。vendor 只与 HSBC 签约，不与客户签约；客户不支付费用，也不参与采购。客户看到的是 **邀请 + 项目 + 交付方**，可以给反馈；看不到价格、评分、招标、比价、评标明细。服务成本由 HSBC 承担，属于私行客户关系权益的一部分。

| 角色 | 是谁 | 做什么 | 不做什么 |
|---|---|---|---|
| **甲方 / 采购方** | HSBC（私行 + 采购 + 合规 + 财务） | 需求聚合、RFP、vendor 准入、评标、定标、合同、SLA、成本、客户邀请 | 不把客户数据给 vendor；不让 vendor 直接获客 |
| **乙方 / 交付方** | 教育机构、医疗机构、律所、税务师、养老/生活方式服务商 | 按规格投标、交付、开票给 HSBC、售后 | 不与客户签约/收费；不接触客户金融数据；不向客户营销 |
| **客户 / 受邀方** | 私行客户/家族成员 | 接受/拒绝邀请、参加、反馈 | 不参与评标；不支付；不看到价格/评分/比价 |
| **银行内部** | RM / 产品 / 采购 / 合规 / 财务 | 需求提出、预算、验收、付款、成本归集 | 不绕过采购与合规 |

**合同与付费**
1. **合同**：HSBC 与 vendor 签主合同 + SOW + DPA + SLA + 保险 + 退出条款；客户不是合同方。
2. **付费**：HSBC 向 vendor 付款；客户不支付、不报销、不签单。
3. **成本**：计入 HSBC 客户关系/营销/服务预算（`cost_center`），按客户/项目归集；不向客户转嫁。
4. **客户侧**：客户获得的是"邀请/席位"，不是"购买服务"；客户侧是否构成应税福利，按属地税法由税务师判断，客户页面不展示价格/税务处理。

**免费服务边界（B 方案）**

| 范围 | 内容 | 合同关系 | 客户付费 |
|---|---|---|---|
| **免费范围** | 特定咨询点：税务初诊、法律事项清单、医疗第二意见、留学方案评估、养老评估等（每项有明确时长/交付物） | **只签 HSBC ↔ vendor**；客户不签 | 0 |
| **超出免费范围** | 深度筹划、架构落地、诉讼/争讼、长期顾问、复杂信托/税务实施 | **客户 ↔ vendor 直接签约**；HSBC 不参与、不收费、不承担交付责任 | 客户自付 |

> **法律特权**：按 B 方案，免费范围只签 HSBC，**接受部分事项无法形成法律特权**。若客户需要法律特权/独立委托关系，属于"超出免费范围"，由客户与律所直接签约，与 HSBC 无关。这是法律专业规则，不是商业选择。

### 5.2 品类与采购策略

| 品类 | 例子 | 采购策略 | 价格权重 | 付费买排名 | 客户看到 |
|---|---|---|---|---|---|
| **税务/会计** | 申报、筹划、审计 | 专业面板、质量优先 | 5–10% | **禁止** | 项目、专家资历、交付方 |
| **法律** | 家事、继承、信托、跨境 | 专业面板、质量优先 | 5–10% | **禁止** | 项目、律所/律师、交付方 |
| **医疗健康** | 家庭医生、第二诊疗、体检、医美/激光 | 资质+安全优先 | 15% | **禁止** | 项目、机构/医生、交付方 |
| **教育** | 留学、国际学校、SEN、技能课程 | 质量+安全+过往成果 | 15% | **禁止** | 课程、师资、时间、交付方 |
| **养老** | 居家护理、社区、记忆照护 | 资质+安全+口碑 | 15% | **禁止** | 项目、机构、护理方案、交付方 |
| **保险** | 寿险、重疾、医疗、财产 | 持牌实体、属地销售 | 监管定价 | **禁止** | 产品、条款（按持牌实体要求） |
| **生活方式** | 旅行、酒店、私厨、酒庄、艺术、赛事 | 竞价 + 质量 | 25% | **可有条件** | 项目、时间、交付方 |
| **安全/慈善** | 家族安全、网安、慈善基金 | 资质+保密+经验 | 10% | **禁止** | 项目、机构、交付方 |

**"付费买排名"的边界**：
- 专业服务（税务/法律/医疗/教育/养老/保险/安全）**禁止**任何形式的付费排序、返点换推荐、成功费分成。
- 生活方式**可以竞价**，但 HSBC 仍按质量/合规评标，价格不是唯一标准；不得让 vendor 直接联系客户营销。
- 所有品类：**客户不看到价格、评分、比价过程**；客户只看到邀请、项目、交付方，并可反馈。

### 5.3 RFP 十步

| # | 步骤 | 负责 | 产出 | SLA |
|---|---|---|---|---|
| 1 | 需求信号 | RM / 产品 | 需求卡（客户原话、人数、预算、时间） | 即时 |
| 2 | 需求聚合 | 产品 / 采购 | 匿名化需求包（可合并同类客户） | 3 个工作日 |
| 3 | 范围与预算 | 产品 / 财务 | SOW、预算区间、成功标准 | 5 个工作日 |
| 4 | Vendor 长名单 | 采购 | 8–15 家合格 vendor | 5 个工作日 |
| 5 | 资格预审 | 采购 / 合规 | 3–5 家 shortlist（牌照、保险、制裁、数据） | 5 个工作日 |
| 6 | 发布 RFP + Q&A | 采购 | RFP 文件、答疑记录 | 10 个工作日 |
| 7 | 密封投标 | Vendor | 方案、报价、假设、SLA、冲突声明 | 10–15 个工作日 |
| 8 | 评标 | 评标委员会 | 质量/合规/价格评分、风险备注 | 5 个工作日 |
| 9 | 定标与合同 | 采购 / 法务 / 财务 | 中标通知、合同、SLA、DPA | 5–10 个工作日 |
| 10 | 客户邀请 + 反馈 | RM / 产品 | 邀请、签到、反馈、复购 | 项目前后 |

### 5.4 评标模型

**专业服务（税务/法律/医疗/教育/养老）**

| 维度 | 权重 | 看什么 |
|---|---|---|
| 质量与资历 | 40 | 牌照、案例、师资/医生/律师资历、成果 |
| 过往记录 | 20 | 同类项目、客户评价、投诉率 |
| 合规与安全 | 20 | 制裁/PEP、保险、数据保护、SEN/医疗安全 |
| 价格 | 10 | 总价、包含项、增项、付款条件 |
| 服务与 SLA | 10 | 响应、退出、售后、语言 |

**生活方式**

| 维度 | 权重 | 看什么 |
|---|---|---|
| 质量与体验 | 30 | 场地、菜单、服务团队、过往活动 |
| 创意与匹配 | 20 | 是否符合家族偏好/主题 |
| 合规与安全 | 15 | 保险、安保、食品/酒类许可 |
| 价格 | 25 | 总价、包含项、取消条款 |
| 服务与 SLA | 10 | 响应、现场支持、售后 |

**评标委员会**：产品（主席）、采购、合规、财务、必要时外部专家；**RM 不参与打分**（避免关系影响），但可提供客户偏好。**定标人 ≠ 评标人**（大额项目双签）。

### 5.5 PB-350 客户邀请（Client-facing）

**页面目标**：客户只看到"HSBC 邀请你参加的项目"，包括项目、交付方、时间地点；**没有价格、没有评分、没有招标/比价/评标明细**。客户可以接受/拒绝/反馈。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `invitation_id` | string | Y | 邀请 |
| `client_id` | string | Y | 客户 |
| `program_id` | string | Y | 项目 |
| `title` | string | Y | 如"经济趋势与科创展览·香港大学 10 讲" |
| `category` | enum | Y | 教育/医疗/养老/生活方式等 |
| `program_description` | text | Y | 项目简介、适合对象、收获 |
| `vendor_name` | string | Y | 交付方（经 HSBC 审核） |
| `format` | enum | Y | 线下/线上/混合 |
| `date_range` | range | Y | 时间 |
| `location` | string | Y | 地点 |
| `audience` | string | Y | 适合年龄/家族成员 |
| `inclusions` | array | Y | 包含项（课程、材料、餐食、接送等） |
| `seats` | int | Y | 名额 |
| `acceptance` | enum | Y | 待回复/接受/拒绝/候补 |
| `feedback` | object | N | 客户反馈（1–5 星 + 文字） |

**客户不会看到**：价格、HSBC 评分、其他 vendor、报价、合同条款、采购邮件、成本。
**客户会看到**：邀请、项目内容、交付方、时间地点、包含项、取消/改期规则。
**客户不支付**：费用由 HSBC 承担；客户无需报销/签单。
**超出免费范围**：不在本页展示；如客户需要，由客户与 vendor 直接签约，HSBC 不参与、不收费、不承担交付责任。

### 5.8 商业与合规红线

| 红线 | 具体 |
|---|---|
| **专业服务不买排名** | 不得以返点、成功费、赞助换推荐；不得按佣金排序 |
| **生活方式可竞价但有边界** | HSBC 仍按质量/合规评标；客户不看到价格/评分/比价 |
| **客户数据不出行** | vendor 只看 cohort 规模与交付信息；不看持仓/账户/交易 |
| **不绕过采购** | 任何 vendor 合作必须有 RFP/合同/DPA/保险 |
| **不绕过合规** | 制裁/PEP/反腐败/利益冲突筛查 |
| **不误导客户** | 不把"HSBC 邀请"说成"HSBC 自营"；明确交付方；不展示价格/评分 |
| **不向客户收费** | 客户不支付、不签约；成本由 HSBC 承担 |
| **不收取暗佣** | 所有费用进 HSBC 合同/成本中心；员工不得收受 vendor 礼品/招待 |

## 6. 四条红线（写进系统）

| 红线 | 具体 | 系统动作 |
|---|---|---|
| **不出税务/法律意见** | 只做情景、清单、转介 | 输出强制带免责声明；禁止"建议你这样做"句式 |
| **不泄露客户数据** | 转介只传需求类别与联系方式（经授权） | 字段级授权；vendor 端看不到持仓/账户/交易 |
| **不误导销售** | 不承诺收益、不承诺税负、不承诺额度 | 敏感词拦截；话术库版本化 |
| **不替代持牌人** | AI 不签字、不直接对客户下结论 | 人工复核 + 留痕 |

## 7. 端到端示例：一次客户对话如何跑完四个舱

> 客户："我明年有一笔 3,000 万美元的税要交，但我不想卖股票；另外我母亲需要养老护理，孩子在申请英国学校。"

| 分钟 | 动作 | 页面 | 输出 |
|---|---|---|---|
| 0–2 | 识别缺口与事件 | PB-300 | 税 3,000 万（M9）、教育（M6）、养老（持续） |
| 2–5 | 融资方案 | PB-310/320 | Lombard 3,500 万（LTV 45%）、成本、追保线 |
| 5–8 | 税务情景 | PB-330 | 卖 vs 押 的税负与流动性对比；转介税务师 |
| 8–12 | 法律服务 | PB-340 | 信托/继承事项清单；转介律师 |
| 12–15 | 服务 / 邀请 | PB-350/360 | 养老 3 家、留学 3 家；HSBC 已筛选，客户收到邀请 |
| 15–20 | 案件工作台 | PB-370 | 4 个案件、负责人、SLA、下一步 |

**RM 得到的不是四份报告，而是一张"接下来 30 天做什么"的清单。**
