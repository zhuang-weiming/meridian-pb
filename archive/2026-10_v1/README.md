## 1. 为什么归档

旧版（v1.5 / v1.4）的核心叙事是：

- “Avaloq 必须被平替”；
- 25 条痛点 / 9 类 / 18 模块 / 7 条旅程；
- D1 以“失能/身故 72 小时”开场；
- 税务写成“银行帮客户报税”；
- 私股写成“Avaloq 缺折价率/抵押金额”。

新版（v2.0）修正为：

- **替换 L1/L2 客户生命周期核心，保留 L0 Avaloq 账本**；
- **阳光旅程在前，压力旅程在后**；
- **失能 ≠ 身故**；没有 probate 的失能旅程不能跑 probate；
- **税务 = adviser-ready tax data pack + 预扣/CRS/FATCA**，不是代客报税；
- **Avaloq TAX2 只处理自己系统内的交易/事件税**，不是全球个人报税；
- **私股是生命周期**，不是贷款产品。

## 4. 旧文档中不要再用的话

- “Avaloq 必须被平替” → 改为“替换 L1/L2，保留 L0”；
- “Avaloq 能生成 UK/HK 个人报税” → 错；
- “Avaloq 缺折价率/抵押金额/风险判断” → 过宽；
- “72 小时拿到钱” → 违规设计；
- “失能后跑 probate” → 法律错误；
- “高净值客户都是悲剧/争产” → 偏差样本，且不适合开场。
