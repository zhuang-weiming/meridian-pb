# 04 — RM 税务指引与专业会计师合作伙伴（UI 规格）

> 这是 RM 的税务导航规格：能说事实/清单/边界/转介，不能说税务意见。
> 用户要求：如果 HSBC 不直接提供全量税务服务，系统要给 RM 税务知识、专业会计师合作伙伴与推荐。
> 本文不是税务建议；具体申报/架构/罚金由持牌税务师/律师处理。

> 用户要求：如果 HSBC 不直接提供 Tax 收入全量服务，系统要给 RM 一些 Tax 知识；并给出专业会计师合作伙伴与推荐。
> 原则：**RM 给“事实/清单/边界/转介”，不给“税务意见”。**
> 这不是税务建议；具体申报/架构/罚金由持牌税务师/律师处理。

---

## 1. RM 能说 / 不能说

| 能说（事实/流程） | 不能说（意见/结论） |
|---|---|
| “您是香港税务居民；这是您的账户/收入事实。” | “您这样安排不用交税。” |
| “这笔收入在系统里是股息/利息/资本利得；预扣是 X。” | “你应该把信托设到开曼。” |
| “CRS/FATCA 是账户报告，不等于个人报税。” | “CRS 报了，你就不用申报。” |
| “这是数据包；请您的会计师确认。” | “我保证没有税务风险。” |
| “这个情况需要税务师/律师；我可以转介。” | “我以前客户都这么做。” |
| “这是税务局/会计师的截止日/责任方。” | “银行可以代您报税/签字。” |

> 一句话：**RM 不做“税务答案”，做“税务导航”。**

---

## 2. RM 的六个问题（发现需求）

1. **税务居民**：过去 12 个月你在哪些国家/地区住？天数？国籍/永居？是否有多个住所？
2. **实体**：你/家族有哪些公司、信托、基金、保险、家办？谁控制/谁受益？
3. **收入**：工资/股息/利息/租金/版税/股权/私股分配/信托分配？来源地/付款方？
4. **资产**：账户/持仓/房产/私股/收藏品/境外资产？成本/估值日？
5. **跨境**：最近/未来 24 个月是否搬迁/移民/购房/卖公司/继承？
6. **申报**：谁在报？报哪些表？有没有历史未报/罚金/CRS/FATCA 问询？

> UI：六个卡片，每个有“已知/未知/需客户确认/需顾问”状态。

## 3. 税务数据包（RM 可发起）

| 包 | 内容 | 来源 | 责任 |
|---|---|---|---|
| **身份包** | 税务居民、TIN、地址、天数、indicia | KYC/客户 | 客户确认 |
| **收入包** | 利息/股息/资本利得/租金/版税/私股分配 | Avaloq/客户 | 银行数据 |
| **成本包** | tax lot/cost basis、公司行动、FX | Avaloq/托管 | 银行数据 |
| **预扣包** | 1042-S/1099/本地预扣/协定 | Avaloq/税务 | 银行 |
| **CRS/FATCA 包** | 分类/控制人/报告 | 合规 | 银行 |
| **行外包** | 客户在其他机构的收入/资产 | 客户/顾问 | 客户 |
| **顾问包** | 数据包 + 问题清单 + 责任矩阵 | 系统 | RM/顾问 |

> UI：一个“生成税务数据包”按钮；勾选字段/期间/顾问；生成 watermarked PDF/CSV；记录 consent。

## 4. 常见场景卡（RM 可读）

| 场景 | RM 要知道 | 红旗/升级 |
|---|---|---|
| **UK→HK** | UK statutory residence/split-year；HK territorial；CRS | 两地居民/双重征税/离境税 |
| **US person** | FATCA/W-8/W-9/1042-S/1099；美国遗产税 | 未申报/放弃国籍/信托 |
| **CRS/FATCA** | 账户分类/控制人/报告；不是个人报税 | 分类矛盾/控制人缺失 |
| **信托** | 信托不是“免税”；受益人/控制人/分配 | 保留权力/虚假信托/21 号公告 |
| **私股/Pre-IPO** | 估值/成本/质押/退出税 | 无估值/无成本/跨境质押 |
| **房产** | 印花税/租金/资本利得/遗产税 | 多实体持有/跨辖区 |
| **历史未报** | 罚金/ remediation/自愿披露 | 不要承诺“没事” |

> UI：卡片可展开；每张卡有“对客户怎么说/什么时候转介/需要什么文件”。

## 5. 合作伙伴推荐（Approved Accountant Panel）

### 5.1 面板字段

| 字段 | 说明 |
|---|---|
| `partner_id` | 内部编号 |
| `name` | 机构名（对外可见需授权） |
| `jurisdictions` | HK/SG/UK/CH/US/… |
| `services` | 个人税/跨境/信托/私股/房产/CRS/FATCA/remediation |
| `languages` | 英/中/… |
| `fee_model` | 按小时/固定/成功费（需披露） |
| `SLA` | 首次响应/交付 |
| `conflict` | 是否与 HSBC 有利益关系 |
| `data_access` | 只读案件/数据包；不接触其他客户 |
| `status` | approved/conditional/suspended |
| `last_review` | 复核日期 |

### 5.2 推荐流程

```
RM 发现需求 → 客户 consent → 选择 2–3 家面板 → 发送数据包/问题清单
→ 客户与 partner 直接签约（或 HSBC 协调） → 交付 → 反馈/质量评分
```

**规则：**

- 客户 **自愿**；不强制；不因不用 partner 而影响银行服务。
- 费用由客户与 partner 约定；HSBC 如收取转介费必须披露。
- Partner 只获得必要字段；不接触其他客户/持仓。
- HSBC 不替 partner 背书结果；不保证税务结论。
- 客户可撤回 consent；数据包版本/访问留痕。

### 5.3 UI

- 在 `m3-taxlegal` 增加 **“RM 指引 / 合作伙伴”** tab。
- 顶部：RM 能说/不能说（红黄绿）。
- 中部：六个问题 + 数据包按钮。
- 下部：Approved Panel 表格（法域/服务/语言/SLA/费用模式/状态）+ “推荐 2–3 家”按钮。
- 右侧：转介流程/consent/证据。
- 角色：RM/TH/Compliance 可见；Client 只看自己已同意的转介。

## 7. 边界

- 不是税务建议；不是报税服务；不保证结果。
- 不隐藏收入/资产；不协助逃避税。
- 不未授权共享客户数据。
- 不推荐未审核 partner；不收取未披露费用。
- 具体法律/税务由持牌顾问确认。
