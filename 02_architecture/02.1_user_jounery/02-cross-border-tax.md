# D2 — 跨境身份/税务：UK→HK 的第一年

> **一句话**：同一个人、同一天，可能是英国和香港两套税制的居民；客户以为银行“应该知道”，银行却在三个系统里查三次，最后给一份 Excel。
> **覆盖痛点**：#2 #17 #18　**类别**：税务・身份授权　**Job**：J4 合规 / J7 证明
> **Demo 时长**：2–3 分钟　**主角**：Ali Abdaal（公开）＋ Mittal 十年影子（公开参照）

---

## 1. 主角与真实锚点

### 1.1 人物

- **Ali Abdaal**：1994 年生于卡拉奇，童年在莱索托，2003 年随母亲/兄弟/祖母移居英国；剑桥医学 2018；NHS 2018–2022；2013 年创办 6med；2017 年做 YouTube；2023 年出版《Feel-Good Productivity》；2024 年结婚并从伦敦移居香港；英国仍有公司、书版税、YouTube 广告账户、Sparkle Studios 股权。
- **Mittal 家族（参照）**：2025 年公开报道其考虑离开英国；英国 non-dom/居留规则的“十年影子”是真实存在的制度现象，用于说明“离境不等于结束”。

### 1.2 真实锚点（2024–2026）

- Ali 2024 年移居香港（本人官网公开简介）；2024–2025 年 Sparkle Studios 成立/任职；2026 年香港购房为设计假设。
- 英国 statutory residence test / split-year treatment、香港 territorial 税制为公开制度；具体适用须税务组复核。
- AUM US$2–5m、按揭金额、税率均为设计假设，不是公开财富事实。

## 2. 痛点：今天会发生什么

| 场景 | 今天 | 代价 |
|---|---|---|
| 身份 | 英国公民/居民、2024 年起香港居住；妻子同在香港（居民身份未公开）；父母在英国/巴基斯坦 | 税务居民是“状态”，不是“国籍”；切换日期/停留天数/split-year 没人能一次说清 |
| 收入 | YouTube 广告（平台 US/IE）、课程（UK 公司）、书版税（UK/US 出版社）、Sparkle 股权 | 同一笔收入在三个辖区、三种性质（劳务/版税/股权）下处理不同 |
| 申报 | 外部税务顾问 + 邮件 + 四套 Excel；银行只做支付/申报接口 | 客户不知道“谁申报什么”；银行不敢给建议；错/漏追溯 5–10 年 |
| 回英 | “如果明年回英国，会不会被追？” | 没有 as-of 情景；没有退出税/影子义务清单 |

**Avaloq 的真实能力（同事口径）**：TAX2 能算税、能生成申报；EasyTax 只做申报；Avaloq 也有扣税/缴税能力；HSBC 对 Avaloq 的主要用法是 CRS/FATCA 尽职调查，不是主动税务服务。

## 3. 新客户体验：Ali 看到的 4 屏

1. **身份时间线**：英国→香港的切换日期、停留天数、split-year 规则；每个身份状态“从哪天生效、到哪天结束”。
2. **三条收入地图**：广告/课程/版税/股权；每条收入的来源地、税务性质、申报责任、付款路径。
3. **“如果明年回英国”情景**：同一笔资产在“继续留港/回英/再移民”三种情景下的税负、申报、流动性。
4. **申报/缴纳包**：哪个辖区、哪张表、谁申报、什么时候到期、谁付；银行只做“事实 + 到期日 + 责任方 + 证据”，建议由外部顾问出。

> 客户不需要银行“给税务建议”；他需要银行**把事实、日期、责任方、证据放在同一张图上**，让他和顾问做决定。

---

## 4. 系统体验：RM/系统看到的 4 屏

1. **TaxResidencyTimeline**：as-of 身份状态机；英国/香港/其他辖区的居留天数、税务居民、协定连结点。
2. **IncomeStream**：每条收入的来源地、性质、付款实体、合同/版税期限、预提/抵扣。
3. **TaxEvent + TaxPayment**：身份切换、购房、赠与、退出、继承触发的税种；纳税时点/估值日；扣缴/缴纳记录。
4. **FilingPackage + EvidencePack**：申报包、顾问意见、客户确认、银行责任边界；任一日期可重放。

| 对象 | 必须回答 | 模块 |

## 6. 建设决策：Avaloq 改造/重写 vs 复用 vs 新增

| 能力 | Avaloq 现状 | 决策 | 说明 | 模块 |
|---|---|---|---|---|
| 税务计算（TAX2） | 有 | **继承** | 事件驱动引擎；不重写 | M13 |
| 申报（EasyTax） | 有 | **继承** | 只做申报；不把申报当“建议” | M13 |
| 扣税/缴税 | 有（同事口径） | **继承** | 扣缴/缴纳复用；不新建支付引擎 | M13/M11 |
| UK/HK 规则包 | CN 2 / HK 0，UK 94 | **扩展** | 补香港零覆盖、split-year、退出税/影子义务 | M13 |
| 身份时间线/as-of | 字段级 | **新建** | 身份是状态机，不是字段 | M12 |
| 收入流/版税/股权 | 账户级 | **新建** | IncomeStream/RoyaltyStream | M12/M13 |
| 申报包/责任边界 | 周边 | **扩展** | FilingPackage + 顾问证据包 | M13/M14/M16 |
| 主动税务建议 | 不做 | **合作** | 外部税务顾问；银行只做协调/证据 | X4/M15 |

> **一句话**：Avaloq 的“算税/申报/扣缴”继承；新建的是“身份时间线 + 收入流 + as-of + 责任边界”。

## 7. Aladdin / Addepar / 合作方

- **Aladdin**：投资组合/风险视图；不承担税务判断。
- **Addepar**：held-away/合并报表；不承担税务判断。
- **外部税务顾问**：建议由顾问出；银行只做 `PartnerRegistry/ReferralCase/EvidencePack`。

## 9. 验收指标与边界

| 指标 | 目标（示意） |
|---|---|
| 回答“我在哪交税” | 从 3 天/3 个系统 → 1 屏/5 分钟 |
| 申报包完整率 | 100% 表/到期日/责任方 |
| 双重征税/漏报 | 0（设计目标） |
| 责任边界 | 每份建议都有外部顾问署名；银行只出事实/证据 |
| as-of 重放 | 任一日期可还原身份/收入/税种 |

**边界**：Ali 为公开人物，AUM/按揭/税率是设计假设；不构成税务意见；具体规则须税务组复核。
