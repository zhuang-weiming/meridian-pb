# D1 — 失能/身故后的 72 小时：何氏家族

> **一句话**：主客户失能后的第 3 天，银行系统仍以他为主客户；妻子、子女、86 岁母亲、6 岁孙女，没有一个人是“独立客户”。
> **覆盖痛点**：#1 #4 #5 #8 #12 #13 #15 #16 #24　**类别**：身份授权・法律文件・家族传承・数据证据　**Job**：J6 传承 / J3 归属 / J7 证明
> **Demo 时长**：3–4 分钟　**主角**：何氏家族（匿名，旧 demo H-7701 扩展）

---

## 1. 主角与真实锚点

### 1.1 人物（匿名示意）

| 成员 | 年龄 | 角色 | 今天在银行系统里 |
|---|---:|---|---|
| 何启明 | 62 | 家族企业创始人、主客户 | 客户、账户持有人、决策人 |
| 陈雅仪 | 59 | 配偶、家庭 CFO | 联名账户持有人，**非独立客户** |
| 何俊轩 | 28 | 长子，准备接班 | 家庭成员，非客户 |
| 何语晴 | 25 | 次女，教育金受益人 | 家庭成员，非客户 |
| 李淑贞 | 86 | 母亲，需照护 | 家庭成员，非客户 |
| 何一诺 | 6 | 孙女，未成年 | 家庭成员，非客户 |

家族资产约 US$30m（示意）：家族企业股权 + 香港/新加坡物业 + 一个香港信托。

### 1.2 真实锚点（2024–2026）

- **何氏家族**：不是公开人物；结构来自旧 demo H-7701 与 RM 访谈的匿名化扩展，姓名/年龄/金额均为示意。
- **许家印信托案（公开极端参照）**：2025-09-16 香港高院任命恒大清盘人为许家印资产接管人，接管范围包括其通过离岸公司间接控制、可能涉及信托架构的资产；法院引用 Chabra 管辖权，强调“实质控制”。严格说，这是**临时接管/保全，不是最终裁定信托无效**；但市场把它视为“信托被击穿”的信号。
- **系统含义**：信托的“不可撤销/离岸”形式不足以自动隔离；银行必须保留**控制权、设立时点、资产来源、受托人独立性、受益人安排**的证据。这不是“多存一份 PDF”，而是“能不能在法院/监管面前证明”。

## 2. 痛点：今天会发生什么（T0–T+90）

| 时点 | 今天会发生什么 | 代价 |
|---|---|---|
| **T0** | 何启明心脏手术后失能。系统仍以他为主客户；账户、授权、受益人、决策人四套记录不同步 | 没有人知道“今天谁能签字” |
| **T+1** | 陈雅仪到银行，只能看“他的报告”；风险偏好、税务居民、家庭目标都是他的 | 她无法回答“我每年能花多少” |
| **T+3** | 家庭要付医疗欠款、护工费、员工工资、贷款利息；账户开始冻结 | 家属垫资/紧急借款/卖资产 |
| **T+7** | 银行等律师/公证/法院文件；香港/新加坡/内地 2–3 个 probate 同时跑 | 3–30 天才知道，数周至数月 |
| **T+30** | 信托受托人决议、POA、监护文件互相冲突；系统只存 PDF | 按旧版执行 → 越权/无效 → 诉讼 |
| **T+90** | 受益人类别、未成年监护、慈善基金会拨款都没人接 | 家族争议、客户流失、声誉 |

**核心断层**：主体断层（逝者/失能者仍是主客户）+ 时间断层（权利没有生效/失效日，死亡/失能不是一等事件）+ 证据断层（文件有版本，但没有冲突裁决/生效链）。

**Avaloq 的真实能力（同事口径）**：CRM 对投资账户有账户/授权/受益人/决策人四类记录；信托产品定义清楚；document 有版本控制，RM 定期与 client review/questionnaire。**这些是强项，继承。**

## 3. 新客户体验：陈雅仪看到的 4 屏

1. **家庭权限地图**：六个人、五种角色、四种权利（信息共享/决策代理/监护/受益）；每个人“现在能做什么/不能做什么”；哪些需要医生证明、哪些需要法院文件、哪些她本人就能决定。
2. **90 天现金计划**：医疗欠款、护工费、员工工资、贷款利息、遗产税备用金；哪些账户可继续支付、哪些被冻结；缺口多少、银行能垫多少、谁批准。
3. **Probate 追踪器**：香港/新加坡/内地三个程序；每个程序的文件清单、到期日、责任方、当前状态；哪一份文件在哪个辖区被承认/不承认。
4. **家庭目标与基金会**：何语晴教育金、何一诺监护/教育、李淑贞养老、慈善基金会 grant 暂停/恢复；每个目标“提出人/受益人/出资方/决策人”四元组。

> 客户不需要懂“五角色四权利”，她只需要看到：**“哪些钱能动、哪些事我能定、下一步是谁。”**

---

## 4. 系统体验：RM/系统看到的 4 屏

1. **T+0 EventSnapshot**：事件时间、触发人、受影响账户/资产、当前有效授权、可继续支付清单、需冻结清单、证据版本。
2. **Authority Graph**：账户/授权/受益人/决策人四类记录 + 五角色/四权利；每条授权的生效日/失效日/地域/事项范围/登记状态。
3. **Probate Case**：跨辖区案件、文件清单、法院/公证/翻译状态、遗产费用、紧急支付、遗产贷款。
4. **Conflict Ruling**：信托契约 v5 vs 法院命令 vs 家族协议 vs 受托人决议；哪一版有效、依据哪一条、谁批准、as-of 是哪一天。

## 5. 功能需求

| 对象 | 必须回答 | 模块 |
|---|---|---|
| `EventSnapshot` | 事件当天，谁有权、谁受益、哪些资产受影响、哪些支付可继续 | M03/M16 |
| `PrimaryClientSwitch` | 主语何时从何启明切到陈雅仪/监护人；切换依据是什么 | M03 |
| `AuthorityDocument` | 生效/失效日、地域/事项范围、登记状态、签名人权限 | M03/M16 |
| `ProbateCase` | 几个辖区、每个程序的文件/到期日/责任方/状态 | M03/M14 |
| `EstateExpense` | 丧葬/医疗/遗产税/员工工资/贷款利息；优先级与追偿 | M10/M14 |
| `EmergencyPayment` | 谁批准、依据哪份文件、上限多少、如何追偿 | M10/M16 |
| `BeneficiaryClass` | 配偶/子女/未出生/收养/代孕/慈善；受益条件 | M01/M02 |

## 6. 建设决策：Avaloq 改造/重写 vs 复用 vs 新增

| 能力 | Avaloq 现状 | 决策 | 说明 | 模块 |
|---|---|---|---|---|
| CRM 账户/授权/受益人/决策人四记录 | 有 | **继承** | 不重写；作为 EventSnapshot 的输入 | M01/M03 |
| 信托产品定义 | 清楚 | **继承** | 信托契约/受益条款直接接 | M04/M05 |
| Document 版本控制 | 有 | **继承** | 版本/归档/问卷复用；不重建文档库 | M16 |
| 事件级联动/T+0 快照 | 无 | **新建** | 失能/身故/争议的一等事件 + 四记录同步 | M03/M16 |
| 跨境 probate | 无 | **新建** | 2–3 个程序、文件/到期日/责任方 | M03/M14 |
| 冲突裁决/生效链 | 无 | **新建** | 契约/法院命令/决议/家族协议的优先级 | M16 |
| 紧急支付/遗产费用 | 部分（支付） | **扩展** | 在支付能力上加 EstateExpense/EmergencyPayment | M10/M14 |
| 受益人类别/监护 | 字段级 | **扩展** | 在 CRM 关系记录上加 BeneficiaryClass/Guardianship | M01/M02 |
| 基金会 grant/payout | 无 | **扩展** | 在 M02/M14 上加 Foundation/Grant/payout | M02/M14 |
| 外部律师/受托人/公证 | 外部 | **合作** | 不建法律服务；只做转介/证据包 | X4/M15/M16 |

> **一句话**：Avaloq 的“四记录 + 信托定义 + 文档版本”继承；真正新建的是“事件 + 快照 + probate + 冲突裁决 + 证据包”。

## 7. Aladdin / Addepar / 合作方

- **Addepar**：家庭合并报表/held-away 聚合；不重写。
- **Aladdin**：本旅程不核心；如涉及投资组合压力测试，可接。
- **外部律师/受托人/公证/税务**：合作；系统只做 `PartnerRegistry/ReferralCase/EvidencePack`，不做法律意见。
- **Avaloq**：继续作为账户/持仓/文档/支付的事实源，直到替代品通过验收。

## 9. 验收指标与边界

| 指标 | 目标（示意） |
|---|---|
| T+0 权限快照 | 事件后 15 分钟内生成 |
| 90 天现金覆盖 | 医疗/照护/工资/利息/遗产税备用金全覆盖 |
| Probate 任务完整率 | 三个辖区文件/到期日/责任方 100% 可见 |
| 无权支付 | 0 笔 |
| 家族 12 个月留存 | 不因主客户失能而流失 |
| 证据可重放 | 任一日期的“谁有权/依据哪份文件”可还原 |

**边界**：何氏为匿名示意；许家印案按公开报道写为“临时接管/保全，不是最终裁定信托无效”；不构成法律/税务意见；对外引用前须法务复核。
