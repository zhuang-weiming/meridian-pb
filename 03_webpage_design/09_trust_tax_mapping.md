# 09 — 信托分配的应税映射：谁申报、按什么税基、如何与 21 号公告对应

> **先声明**：本文是**系统设计与业务控制**文档，不是税务意见，也不能替代持牌税务师/律师的书面意见。所有税率、申报义务、抵扣顺序均须按客户税收居民身份、信托法域、受益人身份、资产类型与交易实质逐案确认。本文明确不设计、也不建议任何隐瞒收入、虚构交易、伪造身份、虚假信托或规避外汇管理的行为。

## 1. 先纠正一个流行误解："马斯克只拿 1 美元工资，所以不缴税"

这个说法在私行圈流传很广，但它把**几个不同的事实**混在了一起。

| 流行说法 | 事实层面 | 对方案的真正含义 |
|---|---|---|
| "马斯克工资 1 美元，所以不缴税" | 他的薪酬主要是**股权激励**，不是工资；期权行权、股份出售会产生税负。2021 年他为行权出售大量特斯拉股票，税负以十亿美元计（公开报道）。 | "低工资"不等于"低税负"；财富来源决定税基。 |
| "用股票质押借钱，不用卖股，所以不缴税" | 质押借款**不是收入**，所以当期不产生所得税；但利息要付，股票要押，股价下跌会追保；借款最终要还。 | 这是**递延**，不是**消除**；是流动性工具，不是税务工具。 |
| "房子、车子、游艇放在公司/信托名下，个人使用不用缴税" | 公司/信托持有资产、个人使用，通常会被认定为**福利、分配或受益**；是否应税、由谁申报，取决于法域与身份。把个人消费记成公司费用，是税务稽查的重点。 | "所有权不在个人名下"不等于"个人没有应税利益"。 |
| "信托里的钱可以随便花，不用申报" | 信托有**委托人、受托人、受益人**三层税务规则；CRS 下账户信息可交换；离岸信托在 21 号公告下已进入全生命周期课税。 | 信托是**保护与治理**工具，不是"隐身衣"。 |
| "银行持有资产，所以客户不缴税" | 银行作为受托人/服务商持有资产，税务义务仍按**受益所有人/委托人/受益人**的税务居民身份判定；银行自身另有营业税/利得税。 | 银行不能、也不应替客户"吸收"税务义务。 |

**结论**：可以复制的是**服务体验**——住得好、出行好、家庭被照顾、资产有结构；**不能复制的是"税负为零"**。任何把"银行/信托持有"讲成"客户永久免税"的方案，都应在合规会上被 challenge。

## 2. 三条底线：什么可以做，什么不可以做

| 可以做（合法税务优化） | 需要持牌意见（灰色，逐案） | 不可以做（违法/高风险） |
|---|---|---|
| 利用居民身份、协定、免税额、扣除项 | 信托/公司架构的真实商业目的 | 隐瞒境外收入、不申报 CRS |
| 时点安排：在价值低点搭建、分批处置 | 受益所有权与保留权力的边界 | 虚假信托、代持、阴阳合同 |
| 保险、年金、慈善等有明确税法依据的工具 | 实物福利的估值与申报 | 把个人消费记成公司/银行费用 |
| 亏损抵扣、捐赠扣除、退休账户 | 跨境间接转让、CFC、经济实质 | 伪造居民身份、假移居 |
| 合法递延（如养老金、保险现金价值） | 信托分配的顺序与抵扣 | 地下钱庄、虚构交易 |

**一条判据**：如果这个结构的**经济实质**是"客户本人控制、本人享受、可随时撤回"，那么无论所有权写谁的名字，税务机关都可能穿透。**控制权越强，保护越弱；税务透明度越高，结构越稳。**

## 3. 税务效率光谱（给 RM 的一张图）

```
绿区：有明确法律依据、可申报、可解释
 ├─ 免税额/扣除项/协定优惠
 ├─ 保险、年金、慈善
 ├─ 时点安排（低点搭建、分批处置）
 └─ 亏损抵扣、捐赠扣除

黄区：需要持牌意见、需要经济实质、需要申报
 ├─ 信托/控股公司持有
 ├─ 股权质押（递延，不是免税）
 ├─ 实物福利（房/车/游艇/派对）
 └─ 跨境架构（37 号文、7 号公告、CFC、CRS）

红区：不做
 ├─ 隐瞒收入/不申报
 ├─ 虚假信托/代持/阴阳合同
 ├─ 个人消费记公司费用
 ├─ 伪造身份/假移居
 └─ 地下钱庄/虚构交易
```

RM 的话术：**"我们可以帮您把结构做稳、把时点排好、把该申报的申报清楚；不能帮您把收入藏起来。"**

## 4. 信托的三层税务事件

信托不是"一个税"，而是**三个时点、三种税基、三类申报人**。

```
L1 信托存续（年度）
   信托取得股息/利息/租金/投资收益
   → 信托层面所得 → 21 号公告：按年 20%，费用不可抵、亏损不结转
   → 谁申报：受托人（并可能穿透至委托人）

L2 信托分配（事件）
   信托向受益人分配现金/资产
   → 分配来源：本金 / 当年收益 / 累计已税收益 / 未税收益 / 资本利得 / 借款
   → 谁申报：受益人（视来源与居民身份）；受托人提供分配凭证

L3 实物受益（事件/持续）
   受益人使用信托/公司持有的房、车、游艇、服务
   → 受益价值（FMV rent/使用费/服务费）
   → 谁申报：受益人/受托人（视法域）；可能构成分配或福利
```

### 4.1 L1：信托存续所得的 21 号公告映射

| 项目 | 规则（按材料口径） | 系统字段 |
|---|---|---|
| 课税对象 | 信托所有收益，无论是否分配 | `trust_income_type` |
| 税率 | 20% | `tax_rate` |
| 可扣除费用 | 管理费/律师费/投顾费**不可抵** | `deductible_expenses = 0` |
| 亏损 | 不得结转 | `loss_carryforward = 0` |
| 申报周期 | 按年 | `tax_year` |
| 过渡期 | 至 2026-10-22（以官方最新为准） | `transition_deadline` |
| 终止 | 按市价清算，清算收益缴税 | `termination_tax` |
| 身份变化 | 转非居民当日视同市价清算 | `residency_change_event` |

**系统动作**：每年生成 `TrustIncomeTaxLot`（所得类型、金额、税额、已缴、凭证），并进入 `TaxReserve`（税务准备金）。**没有完税/计提的收益，不得标记为"可分配已税收益"。**

### 4.2 L2：分配的"税务分层池"

信托分配最容易被问倒的问题不是"交多少税"，而是"**这笔钱是从哪一层出来的**"。

| 来源层 | 定义 | 分配时税务处理 | 系统标记 |
|---|---|---|---|
| **C1 本金（corpus）** | 原始注入资产、资本公积 | 一般不属于所得；但可能涉及资本利得/视同处置 | `source=corpus` |
| **C2 当年已税收益** | 当年收益已按 20% 申报/缴纳 | 分配时不应重复征同一笔所得税；可结转税额抵扣 | `source=current_taxed` |
| **C3 累计已税收益** | 往年已税未分配收益 | 同上；需有税额池 | `source=accumulated_taxed` |
| **C4 未税收益** | 已产生但未申报/未缴 | 先补税，再分配；不得"先分后补" | `source=untaxed` |
| **C5 资本利得** | 处置资产所得 | 按处置规则课税；可能进入 C2/C3 | `source=capital_gain` |
| **C6 借款/垫款** | 信托向受益人借款 | 不是所得；但有利息/受益问题 | `source=loan` |

**分配顺序（建议，需税务师确认）**：先 C2/C3（已税池，带抵扣），再 C1（本金），再 C4（未税，先补税）；C5 按处置时点单独计算；C6 单独台账。**顺序不同，税负与申报人不同，必须在分配前由税务师确认。**

### 4.3 L3：实物受益的估值与申报

| 场景 | 受益价值 | 可能税务处理 | 申报人 |
|---|---|---|---|
| 信托持有住宅，受益人免租居住 | 市场租金（FV） | 可能构成分配/福利 | 受益人/受托人 |
| 信托持有车辆，受益人使用 | 市场租赁价/折旧 | 可能构成福利 | 受益人 |
| 信托持有游艇，受益人度假使用 | 包租市场价/使用天数 | 可能构成福利 | 受益人 |
| 信托支付学费 | 发票金额 | 分配（视来源） | 受益人/受托人 |
| 信托支付派对/活动 | 人均成本 | 受益（可能含宾客） | 受益人/受托人 |
| 信托支付家庭医生/养老 | 服务费 | 分配/福利 | 受益人 |

**系统动作**：每笔实物受益生成 `BenefitValuation`（资产、使用人、期间、估值方法、市场价、申报标记），并进入年度 `BenefitTaxReport`。**没有估值，不得支付。**

## 5. 谁申报：一张 RACI

| 事项 | 受托人（TFS） | 委托人 | 受益人 | 银行（RM/支付） | 外部税务师 | 客户 |
|---|---|---|---|---|---|---|
| 信托年度所得税申报 | **R/A** | C（如穿透） | I | I | C | I |
| CRS/FATCA 申报 | **R/A** | I | I | C（账户数据） | C | I |
| 分配决议 | **R/A** | C（意愿书） | I | I | C | I |
| 分配所得税申报 | C | C | **R/A** | I | C | **A** |
| 实物受益估值 | **R** | I | C | I | **C/A** | I |
| 年度个人申报 | I | **R/A** | **R/A** | I | C | **A** |
| 税务意见 | I | C | C | I | **R/A** | I |
| 付款与凭证 | **R** | I | I | **R** | I | I |

> R=负责执行，A=最终责任，C=被咨询，I=被告知。表中"受托人"指信托服务实体；"银行"指客户关系与支付团队；两者在中国墙与权限上分离。

**关键控制**：**受托人不能既做分配决议、又做税务意见、又做付款复核。** 三权分立：受托人（决议）—税务师（意见）—银行运营（支付/对账）。

## 6. 与 21 号公告"存续收益按年 20%"的对应关系

这是最容易被监管问倒的一处，必须能画出**一条完整的链**：

```
信托取得收益 1,000 万
  → L1：计提 20% = 200 万（无论是否分配）
  → 进入 TaxReserve（税务准备金）
  → 申报/缴纳（受托人）
  → 生成 TrustIncomeTaxLot（已税池）
  → 分配 300 万给受益人
      → 来源：已税池
      → 分配环节不再重复征同一笔所得税
      → 出具分配凭证 + 税额抵扣证明
  → 受益人个人申报（如适用）
```

**如果分配来自未税收益**：
```
未税收益 300 万 → 先补 20% = 60 万 → 再分配 240 万 → 受益人申报（视规则）
```

**如果信托支付学费/房租**：
```
信托资产减少 100 万
  → 先判定来源（已税/未税/本金）
  → 再判定性质（分配/福利/服务采购）
  → 生成 DistributionTaxLot 或 BenefitValuation
  → 受托人决议 + 税务师意见 + 付款凭证
```

**如果信托持有房产供受益人居住**：
```
房产在信托名下 → 受益人使用 → 估值市场租金 120 万/年
  → 判定：分配 or 福利 or 无（视法域）
  → 若应税：受益人申报；受托人出具使用协议与估值
  → 若免税：留存法律依据与估值备查
```

> 以上均为**设计逻辑**，不是税务结论；每一行都需要税务师按客户身份确认。

| 实体 | 关键字段 | 用途 |
|---|---|---|
| `TrustIncomeTaxLot` | trust_id, tax_year, income_type, gross, rate, tax_due, tax_paid, evidence | L1 年度所得 |
| `DistributionTaxLot` | distribution_id, source_layer, tax_base, rate, credit, filing | L2 分配 |

### 7.3 六条硬规则

1. **无来源，不分配**：每笔分配必须标记 C1–C6；标记不了 → 阻断。
2. **无完税/计提，不分配**：未税收益先补税；未计提 → 阻断。
3. **无估值，不实物受益**：房/车/游艇/服务必须有 FMV 与使用记录。
4. **无意见，不跨境**：跨境信托分配、身份变化、终止，必须有税务师意见。
5. **无凭证，不付款**：发票、合同、决议、估值、申报表缺一不可。
6. **双重征税检查**：分配时校验 `tax_credit`，避免同一笔所得税重复征收；校验不了 → 人工复核。

## 8. 算例：500 万美元年度预算怎么走账

假设（演示）：信托当年收益 2,000 万美元，按 20% 计提 400 万美元；年度消费预算 500 万美元；其中房 180 万、车 40 万、旅行 70 万、宴会 40 万、家庭照护 90 万、家政 50 万、安全 30 万。

| 支出 | 金额 | 来源层 | 性质 | 税务处理（示例） | 申报人 |
|---|---|---|---|---|---|
| 住房租金/维护 | 180 万 | C2 已税 | 分配/福利 | 不再重复征同一笔所得税；若为实物福利，按租金估值 | 受益人/受托人 |
| 车辆租赁 | 40 万 | C2 已税 | 福利 | 按使用价值；公司/信托持有则估值 | 受益人 |
| 旅行/酒店 | 70 万 | C2 已税 | 分配 | 凭证；受益人申报（如适用） | 受益人 |
| 宴会 | 40 万 | C2 已税 | 受益 | 人均成本；宾客可能另算 | 受益人/受托人 |
| 家庭照护/教育 | 90 万 | C2 已税 | 分配 | 学费/医疗凭证；受益人申报 | 受益人 |
| 家政/安全 | 80 万 | C2 已税 | 服务采购 | 信托直付；服务税/工资税 | 受托人 |
| **合计** | **500 万** | | | | |

**税务准备金（政策驱动）**：不得设"一刀切"比例。最低值 = max（信托契约/受托人政策、未来 12 个月已知税负、3 个月预算、贷款契约缓冲、压力测试需求）；目标值可高于最低值。每季度复核，年度由受托人委员会 + 税务师签字。低于最低值 → 暂停非必需分配。

**如果 500 万全部来自本金（C1）**：分配环节可能不产生所得税，但可能涉及资本利得/视同处置；且信托本金减少，保护能力下降。**"花本金"不是"零税负"，只是税基不同。**

## 9. "马斯克式"服务，HSBC 可以怎么做得合法

客户真正想要的不是"不缴税"，而是**"不用卖资产、不失去控制、生活品质不降、税务可预期"**。这四件事可以合法做到：

| 想要 | 合法工具 | 代价/边界 |
|---|---|---|
| 不卖股拿现金 | 股票质押（Lombard/SLB） | 利息、追保、估值风险；借款不是收入 |
| 住好房子 | 信托持有住宅 + 使用协议 + 市场租金估值 | 可能构成分配/福利；需申报 |
| 开派对/办活动 | 信托支付 + 人均成本 + 宾客名单 | 可能构成受益；需凭证 |
| 游艇/车队 | 信托持有 + 使用记录 + 包租市场价 | 估值、维护、保险、船员 |
| 家庭照护/教育 | 信托分配/直付 + 发票 | 受益人税负；跨境教育税务 |
| 传承与保护 | 全权信托 + 独立受托人 + 意愿书 | 控制权弱化；注入可能触发 20% |
| 税务可预期 | 税务师年度测算 + 税务准备金 + 申报日历 | 合规成本；不承诺"零税" |

**不能做的"马斯克式"**：
- 把个人住房、派对、游艇记成银行的业务费用；
- 用"银行持有"掩盖受益所有权；
- 用无息贷款/虚假贷款替代分配；
- 不申报 CRS/21 号公告；
- 用信托给客户"随时可取"的控制权，却对外宣称"不可撤销"。

**一句话**：**能设计的是"税务透明下的高品质生活"，不能设计的是"税务隐身"。**

---

## 10. 监管最可能问的五个问题（提前准备答案）

| 问题 | 需要拿出的证据 |
|---|---|
| 这套结构的经济实质是什么？谁控制？谁受益？ | 信托契约、意愿书、董事会决议、受益人名册、控制权图谱 |
| 信托收益有没有按年申报？费用为什么不可抵？ | `TrustIncomeTaxLot`、申报表、缴税凭证、税务师意见 |
| 受益人使用信托资产，是否构成分配/福利？如何估值？ | `BenefitValuation`、租赁/使用协议、市场可比、申报记录 |
| 分配来自本金还是收益？是否重复征税？ | `DistributionTaxLot`、来源层、税额抵扣、银行流水 |
| 跨境架构是否申报？CRS/7 号公告/CFC 怎么处理？ | CRS 报告、税务意见、架构图、登记回执 |

## 11. 结论

1. **"1 美元工资"不是税务方案**，它只是薪酬结构；真正的税负在股权与处置。
2. **"银行/信托持有"不是免税**，它改变的是所有权与申报路径，不改变受益人的应税利益。
3. **21 号公告把离岸信托拉进全生命周期课税**：存续按年 20%、费用不可抵、终止视同清算、转非居民视同处置。
4. **能做的是"税务透明 + 时点 + 结构 + 工具"**；不能做的是"隐瞒 + 虚假 + 不申报"。
5. **系统必须能回答"这笔钱从哪一层出来、谁申报、有没有重复征税"**——这就是 PB-465 存在的理由。
