# 01 — 阳光旅程 S1–S5：家族目标如何实现

> 主角：何氏家族（匿名/示例，非真实客户）；金额/时间线为设计假设。
> 目的：用“好结果”展示 HSBC 的家族核心能力；不是收益承诺。
> 定位：S1–S5 是 **J1/J2/J3/J5/J6/J7** 的具体场景实例，不是全部旅程；完整组合见 [`../03-portfolio/00-journey-portfolio.md`](../03-portfolio/00-journey-portfolio.md)。

## S1 — 教育目标与复利：从“一笔钱”到“18 年计划”

### S1.1 主角与触发

- 何启明 62 岁，家族企业创始人；妻子陈雅仪 59 岁，家庭 CFO；孙女何一诺 6 岁。
- 家族目标：为一诺准备 **US$2m** 教育金（英国/香港/美国三条路径），18 岁可用；同时不影响家族企业现金流。
- 触发：一诺上小学；家族想“现在开始，不要到时临时卖资产”。

### S1.2 目标与约束

| 维度 | 内容 |
|---|---|
| 目标 | 18 岁时 US$2m（今天币值）；可选英国/香港/美国 |
| 时间 | 12 年 |
| 风险 | 不能大亏；回撤 ≤15%；每年可补足 |
| 流动性 | 每年最多用 4%；教育金不动本金 |
| 税务 | 香港税务居民；信托/赠与/跨境需顾问 |
| 治理 | 父母出资；祖母/父母/孩子不同视图；孩子 18 岁后逐步参与 |

### S1.3 现状失败链

| 问题 | 今天 | 代价 |
|---|---|---|
| 目标 | 没有“教育金”对象；只有几个账户/产品 | 不知道够不够 |
| 复利 | 每年看收益率，没有 12 年现金流 | 容易追涨杀跌 |
| 信托 | 信托预算/分配靠 Excel | 分配/税/证据不清 |
| 家庭 | 父母/祖母/孩子看到不同报表 | 家庭会议各说各话 |
| 年度 review | RM 靠 PPT | 没有“目标 vs 实际” |

### S1.4 新体验（客户 4 屏）

1. **教育目标卡**：US$2m、12 年、三条路径、当前 funding ratio 78%。
2. **复利/情景**：5% 现实/3% 保守/7% 乐观；回撤/补足计划。
3. **年度回顾**：实际 vs 目标、费用、税、信托分配、下一步。
4. **家庭视图**：父母看全图；祖母看孙辈；孩子 18 岁后看自己的账户/学习。

### S1.5 系统对象

`Goal`（education）、`GoalFunding`、`CashflowPlan`、`Portfolio`、`IPS`、`TrustBudget`、`BenefitPayment`、`AnnualReview`、`NextGenAccount`。

### S1.6 建设决策

| 能力 | 决策 |
|---|---|
| 组合/交易/账本 | Avaloq |
| 风险/情景 | Aladdin |
| 目标/现金流/年度 review | 新核心 |
| 信托预算/分配 | TFS + 新核心 |
| 家庭视图/下一代 | 新核心 |

### S1.7 好结果

- 12 年后 funding ratio **105%**；一诺拿到英国/香港 offer；信托按预算支付；本金仍在。
- 家庭每年一次“同一张图”会议；孩子 18 岁开独立账户、完成首投/慈善。
- 银行获得：教育金 AUM、信托关系、下一代主关系、转介。

### S1.8 指标

目标达成率、补充率、回撤恢复、年度 review 出席、下一代独立账户/首投。

### S1.9 边界

不承诺收益；情景为假设；税务/信托由顾问/受托人确认。

## S2 — 二代创业：不接班，也能用家族资源

### S2.1 主角与触发

- 何俊轩 28 岁，创始人之子；在伦敦/香港做 **时尚/消费科技** 品牌；不愿直接接家族企业。
- 触发：品牌准备种子轮；需要独立账户、股权结构、供应商融资、导师、家族投资决策。

### S2.2 目标与约束

| 维度 | 内容 |
|---|---|
| 目标 | 3 年内做到区域品牌；首轮 US$3m |
| 家族 | 家族可投 US$500k，但要有投资政策/上限/退出 |
| 独立 | 俊轩要独立，不想被父母控制 |
| 银行 | 独立账户、支付、外汇、融资、导师、HSBC Access/Innovation Banking |
| 治理 | 家族投资委员会/宪章；失败怎么办 |

### S2.3 现状失败链

| 问题 | 今天 | 代价 |
|---|---|---|
| 独立 | 俊轩用父亲的关系/账户 | 权责不清 |
| 股权 | cap table 用 Excel | 融资/稀释/税出错 |
| 融资 | 银行只看抵押/担保 | 创业公司拿不到钱 |
| 家族 | “给不给钱”靠饭桌 | 家庭冲突 |
| 生态 | 没有导师/客户/投资人 | 增长慢 |

### S2.4 新体验（客户 4 屏）

1. **独立身份**：俊轩是独立客户；自己的账户/consent/风险偏好；父母看不到明细（除非同意）。
2. **创业仪表盘**：cap table、 runway、融资、供应商、外汇、保险。
3. **家族投资政策**：家族可投多少、什么条件、谁决定、失败怎么办；有记录。
4. **生态入口**：导师、HSBC Access/Innovation Banking、CIB 客户、行业活动。

### S2.5 系统对象

`NextGenProfile`、`Venture`、`CapTable`、`Guarantee`、`Mentor`、`FamilyInvestmentPolicy`、`Consent`、`Referral`、`AccessOpportunity`。

### S2.6 建设决策

| 能力 | 决策 |
|---|---|
| 独立账户/支付/外汇 | Avaloq |
| 创业融资/担保 | Avaloq 信贷 + 新核心 |
| 家族投资政策/决策 | 新核心 |
| 导师/生态/Access | 合作/CIB |
| 下一代 app | 新核心 |

### S2.7 好结果

- 首轮 **US$3m**（家族 US$500k + 外部）；12 个岗位；进入 HSBC Access 生态；俊轩成为独立客户。
- 家族投资政策/宪章落地；父母/子女关系更好；银行获得下一代主关系、创业融资、家办。

### S2.8 指标

首轮融资、独立账户、家族投资决策记录、导师匹配、下一代 NPS、5 年留存。

### S2.9 边界

不承诺融资/估值；创业失败是可能的；银行不做创业建议；担保/信贷按风险审批。

## S3 — 跨境家庭搬迁：从伦敦到香港/新加坡

### S3.1 主角与触发

- 何氏家庭：何启明/陈雅仪，两个孩子（28/25），祖母 86 岁；从伦敦搬回香港，可能再去新加坡。
- 触发：企业重心回亚洲；孩子教育/工作；祖母医疗；资产/信托跨 UK/HK/SG。

### S3.2 目标与约束

| 维度 | 内容 |
|---|---|
| 时间 | 6 个月内安顿 |
| 账户 | UK/HK/SG 账户/信用卡/按揭 |
| 税务 | UK/HK 居民切换、split-year、CRS/FATCA |
| 实体 | BVI/HK/SG 公司/信托 |
| 家庭 | 学校/医疗/住房/保险 |
| 合规 | 数据出境/consent/KYC |

### S3.3 现状失败链

| 问题 | 今天 | 代价 |
|---|---|---|
| KYC | 每个实体重复 | 2–3 个月 |
| 税务 | 三套 Excel/顾问 | 错/漏 |
| 账户 | 分行/电话/邮件 | 体验差 |
| 家庭 | 每个人自己跑 | 冲突/延误 |
| 数据 | 跨境邮件/网盘 | 合规风险 |

### S3.4 新体验（客户 4 屏）

1. **搬迁地图**：6 个月、5 个工作流（银行/税务/住房/学校/医疗/传承）、责任方/到期日。
2. **一次 KYC**：同一家庭/实体复用；按辖区补差异；consent。
3. **税务时间线**：UK/HK 居民切换、split-year、CRS/FATCA、顾问。
4. **家庭安顿**：账户/信用卡/按揭/保险/学校/医疗；每个人自己的视图。

### S3.5 系统对象

`RelocationCase`、`Jurisdiction`、`TaxResidency`、`Entity`、`Consent`、`ServiceTask`、`Partner`、`KYCReuse`。

### S3.6 建设决策

| 能力 | 决策 |
|---|---|
| 账户/支付/外汇 | Avaloq |
| 跨境案件/任务 | 新核心 |
| 税务居民/税包 | 新核心 + 顾问 |
| KYC/合规 | 新核心 + 现有 KYC |
| 学校/医疗/住房 | 合作 |

### S3.7 好结果

- 6 个月安顿；KYC 重复减少 60%；0 合规事件；家庭留在 HSBC；孩子进入本地学校/大学；祖母医疗接上。
- 银行获得：跨 3 辖区关系、存款/按揭/投资/信托。

### S3.8 指标

搬迁完成时间、重复 KYC 次数、合规事件、客户留存、跨辖区产品渗透。

### S3.9 边界

税务/签证/学校/医疗由专业顾问/机构；银行只做协调/数据/证据。

## S4 — 企业家退出：从“公司值钱”到“家族有钱”

### S4.1 主角与触发

- 何启明 58 岁，家族企业准备卖 **60%** 给战略买家/IPO；估值 **US$300m**；员工/家族/慈善都在场。
- 触发：买家 term sheet；lock-up/ earn-out；税；信托/家办；下一代。

### S4.2 目标与约束

| 维度 | 内容 |
|---|---|
| 流动性 | 部分现金/部分股权/earn-out |
| 税 | 香港/跨境/信托；需顾问 |
| 控制 | 保留 40%；董事会/否决 |
| 家族 | 下一代角色；家族宪章；慈善 |
| 家办 | 设 SFO；投资/信贷/信托 |
| 风险 | 集中度/锁定期/ earn-out 失败 |

### S4.3 现状失败链

| 问题 | 今天 | 代价 |
|---|---|---|
| 估值 | 投行/税务/银行三个数 | 贷多/贷少/税错 |
| 税 | 卖/信托/跨境分开算 | 税负/合规 |
| 信托 | 设立/分配/受益人靠律师 | 慢/贵 |
| 家办 | 设不设/怎么设 | 家族冲突 |
| 下一代 | 没角色 | 流失 |

### S4.4 新体验（客户 4 屏）

1. **退出全景**：现金/股权/earn-out；税后；控制权；时间。
2. **卖 vs 押 vs 信托**：三种路径的税后/控制/流动性/风险。
3. **家族办公室**：设立/运营/投资政策/团队/成本。
4. **下一代/慈善**：角色/教育/基金会；家族宪章。

### S4.5 系统对象

`ExitEvent`、`Valuation`、`TaxScenario`、`Trust`、`FamilyOffice`、`Liquidity`、`EarnOut`、`NextGenPlan`、`Foundation`。

### S4.6 建设决策

| 能力 | 决策 |
|---|---|
| 估值/投行 | 合作/CIB |
| 税 | 顾问 + 新核心税包 |
| 信托/家办 | TFS + 新核心 |
| 信贷/质押 | 自研新核心（参考 Avaloq 能力） |
| 家族治理 | 新核心 |

### S4.7 好结果

- 交易完成；税后财富 **70%** 分散到组合/信托/家办；保留 40% 控制；SFO 设立；下一代进入投资委员会观察员；慈善基金会启动。
- 银行获得：家办 AUA、信托、信贷、投资、下一代。

### S4.8 指标

退出完成、税后财富、家办设立、信托 AUM、下一代参与、控制权保留。

### S4.9 边界

不承诺估值/交易；税/法律由顾问；投资有风险。

## S5 — 家族办公室与治理：从“有钱”到“有操作系统”

### S5.1 主角与触发

- 何氏家族：3 个分支、5 个实体、2 个信托、跨 HK/SG/UK；现有 MFO/律师/会计师各自为政。
- 触发：何启明 65 岁，想“下一代能接、家办能转”；设 SFO。

### S5.2 目标与约束

| 维度 | 内容 |
|---|---|
| 家办 | SFO；CEO/CIO/COO；成本 |
| 合并 | 银行/外部/信托/私股/房产/收藏品 |
| 投资 | IPS/SAA/TAA/风险/流动性 |
| 治理 | 家族宪章/ council/接班 |
| 下一代 | 课程/导师/委员会观察/创业/慈善 |
| 慈善 | 基金会/ grant/ impact |

### S5.3 现状失败链

| 问题 | 今天 | 代价 |
|---|---|---|
| 合并 | 5 个 portal/Excel | 看不清 |
| 投资 | 每个经理一套 | 风险/成本 |
| 治理 | 没有宪章 | 冲突 |
| 下一代 | 没角色 | 流失 |
| 慈善 | 临时捐 | 无 impact |

### S5.4 新体验（客户 4 屏）

1. **家族办公室 dashboard**：合并资产/负债/现金流/风险/成本。
2. **投资政策**：IPS/SAA/TAA/集中度/流动性；实际 vs 政策。
3. **治理**：宪章/ council/会议/决策/接班。
4. **下一代/慈善**：课程/导师/委员会/ grant/ impact。

### S5.5 系统对象

`FamilyOffice`、`ConsolidatedView`、`InvestmentPolicy`、`FamilyCharter`、`Council`、`NextGenPlan`、`Philanthropy`、`FOReport`。

### S5.6 建设决策

| 能力 | 决策 |
|---|---|
| 合并报表 | Addepar/合作 + 新核心 |
| 投资/风险 | Aladdin |
| 信托/慈善 | TFS |
| 治理/下一代 | 新核心 |
| CIB/Access | 合作 |

### S5.7 好结果

- SFO 设立；合并 **US$500m** AUA；投资政策/风险/成本透明；家族宪章/ council；下一代进入委员会；慈善 grant 有 impact。
- 银行成为家办主银行/主托管/主信贷；下一代留存。

### S5.8 指标

家办 AUA、合并覆盖率、IPS 合规、治理里程碑、下一代参与、成本/收入。

### S5.9 边界

家办可能有现有 provider；HSBC 做补充/编排，不强行替代；投资/法律/税务责任边界。
